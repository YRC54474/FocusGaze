# วิธีใช้ gaze-model (Focus Time)

โฟลเดอร์นี้ก็อปทั้งหมดไปวางในเว็บได้เลย ไม่ต้องรู้เรื่อง machine learning
ไม่ต้องแก้อะไรข้างใน แค่เรียกใช้ตามโค้ดด้านล่าง

## เริ่มใช้งานใน 5 บรรทัด

```js
import { GazeModel } from './gaze-model.js';
const model = await GazeModel.load('./gaze-model.json');
// landmarks = ผลลัพธ์จาก MediaPipe FaceLandmarker (478 จุด)
// blendshapes = ผลลัพธ์ faceBlendshapes จาก MediaPipe (ใส่หรือไม่ใส่ก็ได้)
const p = model.predict(landmarks, blendshapes);
// p = { x, y, confidence, zone } — x,y คือตำแหน่งบนจอ 0-1 (0=ซ้าย/บน, 1=ขวา/ล่าง)
// zone = { col: 0-2, row: 0-1 } — ตำแหน่งแบบหยาบ ใช้ตัวนี้เป็นหลัก อ่านหัวข้อถัดไป
```

**ไม่ต้องคาลิเบรตอะไรทั้งสิ้น** โมเดลปรับตัวให้เข้ากับแต่ละคนเองอัตโนมัติจากเฟรมที่เห็นระหว่างใช้งาน
ไม่มี `quickCalibrate` ไม่มี `localStorage` ไม่ต้องขอผู้ใช้ทำอะไรพิเศษก่อนใช้งาน

## ใช้ `zone` เป็นหลัก อย่าออกแบบละเอียดกว่านี้

โมเดลนี้แม่นยำแนวนอน (ซ้าย-ขวา) ดีกว่าแนวตั้ง (บน-ล่าง) มาก — ความคลาดเคลื่อนแนวตั้งจริงอยู่ที่ประมาณ 216 พิกเซล
บนจอสูง 1080 พิกเซล **ไม่พอที่จะแบ่งเป็น 3 แถวขึ้นไปอย่างน่าเชื่อถือ** จึงให้ `zone` แบ่งเป็น
**3 คอลัมน์ (แนวนอน) x 2 แถว (แนวตั้ง)** เท่านั้น — ถ้าจะออกแบบ UI ที่อิงตำแหน่งการมอง
(เช่น เดาว่าผู้ใช้มองฝั่งซ้าย/กลาง/ขวาของจอ, บน/ล่าง) ให้ยึดตาม `zone` เป็นหลัก
**อย่าพยายามแบ่งละเอียดกว่านี้เอง** จาก `x, y` ตรงๆ เพราะความแม่นยำจริงไม่รองรับ

## confidence บอกอะไร ควรทำยังไง

| confidence | ความหมาย | ควรทำ |
|---|---|---|
| 0.7 ขึ้นไป | มั่นใจสูง | ใช้ค่า x, y, zone ได้ตามปกติ |
| 0.3 – 0.7 | มั่นใจปานกลาง | ใช้ได้ แต่ระวังอาจคลาดเคลื่อน ไม่ควรใช้ตัดสินใจสำคัญทันที |
| ต่ำกว่า 0.3 | มั่นใจต่ำ | อย่าใช้ค่า x, y, zone ตอนนี้ |
| confidence = 0 | ไม่เจอหน้า | x, y, zone จะเป็น null ห้ามใช้ |

confidence จะต่ำเวลา: ไม่เจอหน้า / กำลังกะพริบตา / หันหน้าออกจากช่วงที่เทรนไว้มาก

**confidence ไม่ได้บอกเรื่อง "เพิ่งขยับท่านั่ง" โดยเฉพาะ** — ระบบปรับตัวให้เข้ากับแต่ละคน
โดยดูค่าเฉลี่ยของฟีเจอร์สะสมไปเรื่อยๆ ไม่มีตัวตรวจจับแยกว่า "เพิ่งเปลี่ยนท่า" แค่ค่อยๆ
ปรับตัวเข้าหาท่าใหม่เองตามธรรมชาติ **ดังนั้น 10-20 วินาทีแรกหลังเปิดกล้องความแม่นยำจะต่ำกว่าปกติ**
(วัดจริงแล้ว: ≤5 วินาทีแรก ~385px, 10 วินาที ~337px, 20 วินาที ~271px ค่อยๆ ดีขึ้น)
เป็นเรื่องปกติ ให้เช็ค confidence เสมอโดยเฉพาะช่วงแรกที่เปิดกล้อง

## ความแม่นยำที่คาดหวังได้

ตัวเลขนี้มาจากการทดสอบแบบ "เจอคนที่โมเดลไม่เคยเห็นมาก่อน" (จำลองสถานการณ์ผู้ใช้ใหม่จริง)
รวมผลของระบบปรับตัวอัตโนมัติแล้ว (ไม่ใช่ตัวเลขก่อนปรับตัว):

- แนวนอน (ซ้าย-ขวา): คลาดเคลื่อนเฉลี่ยประมาณ 161 พิกเซล
- แนวตั้ง (บน-ล่าง): คลาดเคลื่อนเฉลี่ยประมาณ 216 พิกเซล (นี่คือเหตุผลที่ zone แบ่งแนวตั้งแค่ 2 แถว)
- รวมทั้งสองแกน (ระยะทางตรงจากจุดจริง): ประมาณ 311 พิกเซล
- โมเดลเทรนจากผู้เข้าร่วม 15 คน (24407 แถวข้อมูล) — ยิ่งมีคนเก็บข้อมูลเยอะ ตัวเลขนี้ยิ่งน่าเชื่อถือ

## สิ่งที่โมเดลนี้ "ทำไม่ได้"

- ไม่รู้ว่าผู้ใช้ "ตั้งใจ" มองจริงไหม รู้แค่ทิศทางสายตาโดยประมาณเท่านั้น
- **ไม่แม่นพอสำหรับ UI ละเอียด** เช่น เลือกปุ่มเล็กๆ ด้วยสายตา — ใช้ `zone` (3x2) เป็นสัญญาณหยาบที่สุดเท่านั้น
- แม่นยำน้อยลงถ้าผู้ใช้หันหน้าออกจากจอมาก (เกินช่วงที่เทรนไว้) — โมเดลจะลด confidence ให้เองในกรณีนี้
- ไม่ได้เทรนกับสภาพแสง/แว่นตา/กล้องทุกแบบ ถ้าคนใช้งานต่างจากคนที่เก็บข้อมูลไว้มาก อาจคลาดเคลื่อนมากกว่าตัวเลขด้านบน
- ระบบปรับตัวอัตโนมัติต้องใช้เวลา 10-20 วินาทีแรกหลังเปิดกล้องก่อนจะแม่นเต็มที่ — ดูหัวข้อ confidence ด้านบน
  (ถ้าผู้ใช้ขยับท่านั่งแรงๆ ระหว่างใช้งาน ความแม่นยำจะค่อยๆ ปรับตัวตามท่าใหม่เองเช่นกัน แต่ระบบไม่มีตัวแจ้งเตือนแยกว่า "เพิ่งขยับ")
- มี smoothing ในตัว (ทำให้จุดไม่กระตุก) แต่ก็แปลว่ามี "ดีเลย์" เล็กน้อยเวลาสายตาเปลี่ยนทิศทางเร็วๆ ไม่เหมาะกับงานที่ต้องการความไวสูงมาก เช่น เกมที่ต้อง "ยิง" ด้วยสายตาแบบทันที
- ไม่ใช่ face recognition ไม่รู้ว่าใครเป็นใคร และไม่เก็บภาพหรือวิดีโอใดๆ ทั้งสิ้น

## วิธีตรวจว่าต่อเข้าเว็บถูกไหม

เปิด `verify.html` ในโฟลเดอร์นี้ผ่าน local server (เช่นรัน `python3 -m http.server` ในโฟลเดอร์นี้แล้วเปิด
`http://localhost:8000/verify.html` — เปิดไฟล์ตรงๆ แบบ `file://` จะติด browser security ไม่ทำงาน) แล้วกดปุ่มเดียว

- ขึ้นเขียวครบ → ต่อโค้ดถูกต้อง ใช้งานได้เลย
- ขึ้นแดง → **แปลว่าต่อโค้ดผิด ไม่ใช่โมเดลแม่นน้อย** ให้เช็คว่า:
  1. ก๊อปมาครบทั้ง 3 ไฟล์ (`gaze-model.js`, `gaze-model.json`, `test-vectors.json`) อยู่โฟลเดอร์เดียวกัน
  2. เรียกใช้ตรงตามโค้ดตัวอย่างด้านบนเป๊ะๆ ไม่ได้แก้ไขไฟล์ข้างใน
  3. เปิดผ่าน server จริงๆ ไม่ใช่เปิดไฟล์ตรงๆ

อยากดูตัวอย่างการทำงานจริงแบบเปิดกล้อง ลองเปิด `demo.html` ในโฟลเดอร์เดียวกัน
